Зачетное задание 3.

Реализовать стандартные функции работы с СИ-строками на языке ассемблера и дополнить файл strings.inc этими функциям.

Должны быть реализованы следующие функции:
	- size_t strlen (const char* str);
	- char* strstr (const char* str, const char* strSearch);
	- char* strchr (const char* str, int c);
	- char* strcpy (char* dst, const char* src);
	- char* strcat (char* dst, const char* src);
	- int strcmp (const char* string1, const char* string2);
	- int stricmp (const char* string1, const char* string2);
	- long strtol (const char* string, char** end_ptr, int base);	// В случае нашей архитектуры long - это WORD (2 байта)
	- char* strdup (const char* strSource);  // https://learn.microsoft.com/ru-ru/cpp/c-runtime-library/reference/strdup-wcsdup-mbsdup?view=msvc-170
	

ПРОГРАММА ЛОГИЧЕСКИ ДОЛЖНА БЫТЬ РАЗБИТА НА ФУНКЦИИ. (ПЕРЕДАЧА АРГУМЕНТОВ В ФУНКЦИИ ЧЕРЕЗ СОГЛАШЕНИЕ О ВЫЗОВАХ CDECL). Свести хранение всех данных в локальных переменных стековых фреймов (минимизировать использование глобальной области памяти).


ВСЕ СТРОКИ НЕОБХОДИМО ХРАНИТЬ В ДИНАМИЧЕСКИ РАСПРЕДЛЕЯЕМОЙ ОБЛАСТИ ПАМЯТИ (в частности в функции strdup необходимо выделять память динамически и соответственно необходимо продумать возвращаемое значение). ФУНКЦИИ РАБОТЫ С ДИНАМИЧЕСКИ РАСПРЕДЕЛЯЕМОЙ ПАМЯТЬЮ НЕОБХОДИМО ВЫНЕСТИ В ОТДЕЛЬНЫЙ .INC ФАЙЛ И ВКЛЮЧАТЬ, ГДЕ НЕОБХОДИМО.

ОБЯЗАТЕЛЬНО ОПИСАТЬ ТЕСТИРОВАНИЕ ВСЕХ ФУНКЦИЙ.	
В качестве тестирования некоторых функций НУЖНО написать программу, которая считывает с двух разных файлов (пути до файлов программа запрашивает у пользователя и хранит в виде СИ-строк) весь текст за раз (в динамическую память, соответственно необходимо будет реализовать функцию подсчета размера файла). 
Отдельно производит разделение текста на массив строк по любым символам, например, разделять по '\n' (для каждой строки отдельно выделять память, соответственно необходимо будет расчитывать длину каждой строки).
Сравнивает два массива строк и выводит результат сравнения в формате: (индекс несовпадающих строк; индекс несовпадающего символа внутри несовпадающей строки).
ВСЕ ФУНКЦИИ РАБОТЫ С ФАЙЛАМИ НЕОБХОДИМО ВЫНЕСТИ В ОТДЕЛЬНЫЙ .INC ФАЙЛ И ВКЛЮЧАТЬ, ГДЕ НЕОБХОДИМО.

Остальные фукнции, которые не удалось применить в основном тесте, тестировать отдельно в произвольном формате.
